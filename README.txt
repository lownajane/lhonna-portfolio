SETUP (XAMPP)
1. Copy this folder's contents into C:\xampp\htdocs\portfolio\ together with your style.css, script.js and all images.
2. Start Apache + MySQL. In phpMyAdmin, Import > database.sql.
3. Edit DB_USER / DB_PASS in config.php if needed.
4. Open http://localhost/portfolio/setup_admin.php, create the admin, then DELETE setup_admin.php.
5. Log in at /portfolio/admin/login.php.
